## 五、已知缺口（按影响排序）

1. **5 款内置预设没有 relighting 参数**：`lighting_presets/builtins.rs` 里 `relighting` 出现 0 次，启用新管线后它们全部落到同一套默认值（白环境 1.0 + 中心暖点光 0.85 / r0.75 / soft0.8），视觉上互相不可区分。这是"预设看起来不对"的直接原因，不是参数调得差。
2. **单点光模型**：没有 z 轴/高度，没有平行光/锥形光，不支持多光源；边缘光靠 CSS `drop-shadow` 近似。
3. **没有去色通道**：`monochrome` 只存在于未提交的 Task 6 半成品里，本快照没有。
4. **Task 6 未实现**：15 款预设、去色通道、旧 5 款基线快照都已回退，不在本次交付里。
5. **Live2D 本体不走 CSS 滤镜**：ready 模型只能靠绑定在舞台上的单个 Filter，观感与静态立绘不完全一致。

## 六、下一步建议

1. 先给 5 款内置预设各补一套 `relighting` 参数（最小闭环，改 `builtins.rs` + 快照测试即可验证），这一步能立刻解决"预设看不出区别"。
2. 再决定是否把多光源（点/环境/平行/锥形，上限 8 盏）做进生产：需要动 `types.ts` / `glsl.ts` / `math.ts` / `RelightingPanel.vue` / `relighting.rs`，并处理 `.linglight` 与 settings 的旧格式迁移。
3. 每一步都按现有节奏走：先真 RED 再实现、只暂存自己 allowlist 的文件、父代理复验、独立提交。
4. 视觉与性能验收单独安排，不要用单测结果替代。
